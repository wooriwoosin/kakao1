잘못된 응대 사례 모음 (카카오톡)

업체 응대 과정에서 반복적으로 발생하는 실수 7가지를 정리했습니다.

응답 속도

업체를 기다리게 하지 않습니다

응답 지연

문제

메시지를 읽은 뒤 아무 안내 없이 5분 이상 응답하지 않는 경우입니다.

개선

즉시 답변이 어렵다면 "잠시만요, 확인 후 안내드리겠습니다."라고 먼저 안내합니다.읽고 나서 아무 말 없이 두는 것이 가장 큰 불만 요인입니다.

확인 지연 시 중간 안내 미전달

문제

"확인 후 안내드리겠습니다."라고 답한 뒤 10~30분간 아무 안내가 없어, 업체가 다시 문의하게 되는 경우입니다.

개선

확인이 길어지면 "현재 확인 중이며, 조금 더 시간이 소요될 예정입니다."라고 중간 상황을 공유합니다.

말투와 태도

같은 내용도 표현이 신뢰를 만듭니다

반말 또는 단답형 응대

문제

"가능", "확인" 등 반말이나 성의 없는 단답으로 응대하는 경우입니다.

개선

항상 존댓말을 사용하고, 완결된 문장으로 답변합니다.

예시
지금가능
개선네, 가능합니다. 바로 진행하겠습니다.

딱딱하거나 오해를 살 수 있는 말투

문제

"말씀드렸잖아요.", "위에 말씀드렸는데요.", "제 말이 맞아요."처럼 상대방이 불쾌하게 느낄 수 있는 표현을 쓰는 경우입니다.

개선

같은 내용도 부드러운 표현으로 바꿔 전달합니다.

예시
지금위에 말씀드렸는데요.
개선다시 한번 안내드리겠습니다.

응대 방식

확인하고, 바로 답하고, 내부 논의는 내부에서

확인 없이 바로 "모른다"고 답변

문제

질문을 받자마자 "잘 모르겠습니다.", "안 됩니다."라고 답변하는 경우입니다.

개선

먼저 "확인 후 안내드리겠습니다."라고 안내한 뒤 실제로 확인하고, 최종적으로 불가능한 경우에만 사유와 함께 안내합니다.

업체 카카오톡방에서 내부 직원 태그

문제

업체가 함께 있는 대화방에서 내부 직원을 직접 태그하는 경우입니다.업체에서 카톡 알림 자체를 불편해할 수 있습니다.

개선

내부 전달이 필요한 내용은 반드시 웍스를 통해 전달합니다. 업체 방에서는 내부 논의가 노출되지 않도록 합니다.

불필요한 재질문

문제

업체가 내용을 명확하게 전달했음에도 되묻는 행위입니다.

예시
개통 부탁드립니다. → 바로 개통해드리면 될까요?
한 줄 요약

업체 문의에는 5분 안에 먼저 반응하고, 존댓말 완결 문장으로 답하며, 확인한 문의는 끝까지 책임집니다.
